NighasanSchools – Free Website Demo

1. index.html को मोबाइल/कंप्यूटर में Chrome से खोलकर डेमो देखें।
2. मुफ्त में ऑनलाइन डालने के लिए GitHub पर अकाउंट बनाकर नया Public repository बनाएं।
3. इस ZIP की सामग्री repository में upload करें और repository Settings > Pages में Deploy from a branch चुनें; branch main और folder /(root) चुनकर Save करें।
4. कुछ मिनट बाद GitHub Pages URL मिलेगा।

महत्वपूर्ण:
- यह केवल फ्रंट-एंड डेमो है। अभी वास्तविक पेमेंट या full-content unlock नहीं है।
- पूरी DOCX फाइलें इस पैकेज में नहीं रखी गई हैं ताकि वे सार्वजनिक रूप से डाउनलोड न हो जाएँ।
- वास्तविक भुगतान के लिए अभिभावक/वयस्क द्वारा payment provider/KYC और सुरक्षित backend की व्यवस्था आवश्यक होगी।
- ऑनलाइन पढ़ने पर भी screenshots/copying पूरी तरह रोकी नहीं जा सकती।
